# 🏀 led-hoops

A retro, dynamic basketball scoreboard built as a Scrimba challenge. This project highlights responsive layouts using CSS Grid and Flexbox, paired with JavaScript DOM manipulation.

## ✨ Features

*   **Retro Aesthetic:** Integrates the `Cursed Timer ULiL` monospaced font to replicate a realistic LED stadium display.
*   **Robust Layout:** Combines **CSS Grid** for the macro-layout and **Flexbox** for precise component alignment.
*   **Interactive Controls:** Fully functional score tracking for both **Home** and **Guest** teams.

## 🛠️ Tech Stack

*   **HTML5** – Semantic structure
*   **CSS3** – Grid layout, Flexbox, custom web fonts (`@import`)
*   **JavaScript (ES6)** – State management and live DOM updates

## 🚀 Local Setup

To run this project locally:

1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Open the `index.html` file directly in your browser.

## 📝 Key Takeaways (Senior Dev Insights)
Building this project helped reinforce best practices regarding:
*   Advanced grid structures using `grid-column: span 2` to create multi-column footers smoothly.
*   Debugging case-sensitivity bugs in CSS class naming (e.g., maintaining consistency between `.column` and `.Column`).
*   Proper handling of custom external web fonts containing spaces using strict font-family quotation rules.
